# TekiDeki.github.io

Pagina de prezentare TekiDeki pentru **https://tekideki.github.io/**.

- `index.html` este o pagină statică, responsive, fără build și fără dependențe externe.
- Prezintă toolbox-ul **https://freehtml.dev/**, aplicația recentă Hash-Desk și proiectele deschise de pe GitHub.
- Tema dark/light se alege din pagină și se păstrează local; conținutul rămâne disponibil și fără JavaScript.
- `robots.txt` și `sitemap.xml` păstrează indexarea și sitemap-urile uneltelor găzduite pe acest domeniu.
